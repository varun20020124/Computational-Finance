# Computational Finance

A collection of C++ projects exploring computational methods, financial data analysis, and quantitative finance.

This repository is organized as a collection of independent projects. Each project lives in its own directory and contains its own source code, data files, documentation, and instructions for compilation and execution.

## Projects

### Baa Rate Analyzer

`Baa_Rate_Analyzer/`

A C++ program for loading historical Moody's Baa corporate bond rate data, querying the rate associated with a specific month, and comparing that rate with the historical average of the dataset.

The project demonstrates:

* File input using C++ file streams
* CSV parsing
* String manipulation
* Vectors
* Searching financial time-series data
* Basic statistical calculations
* Command-line user interaction
* Input validation and error handling

See [`Baa_Rate_Analyzer/README.md`](Baa_Rate_Analyzer/README.md) for project-specific documentation and instructions.
