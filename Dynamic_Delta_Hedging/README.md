# Dynamic Delta Hedging

Interim Project 1 for **ISyE 6767 – Systems and Computation for Finance, Fall 2026**.

This project implements and evaluates a dynamic delta-hedging strategy for European options using the Black-Scholes model. The implementation is written primarily in C++ and uses Python only to visualize results generated by the C++ program.

The project contains two main tasks:

1. Test dynamic delta hedging using simulated stock-price paths.
2. Apply the strategy to historical GOOG stock and option market data.

## Model Components

### Option

`Option` stores the contract-level information for a European option:

- strike price
- expiration date
- call/put flag

---

### BlackScholesModel

`BlackScholesModel` implements:

- Black-Scholes option pricing
- Black-Scholes Delta
- standard normal CDF
- implied-volatility estimation using binary search

For a call option,

\[
C = S N(d_1)-Ke^{-r\tau}N(d_2),
\]

where

\[
d_1 =
\frac{\ln(S/K)+(r+\sigma^2/2)\tau}
{\sigma\sqrt{\tau}},
\qquad
d_2=d_1-\sigma\sqrt{\tau}.
\]

The call Delta is

\[
\Delta=N(d_1).
\]

---

### Simulation

`Simulation` generates stock-price paths according to

\[
S_{t+\Delta t}
=
S_t+\mu S_t\Delta t
+\sigma S_t\sqrt{\Delta t}Z_t,
\]

where \(Z_t\) is a standard normal random variable.

The simulation also calculates the corresponding Black-Scholes option-price paths and exports both sets of paths to CSV files.

---

### DeltaHedger

`DeltaHedger` implements the dynamic hedge.

The initial bank position is

\[
B_0=V_0-\Delta_0S_0.
\]

The cumulative hedging error at date \(t_i\) is

\[
HE_i
=
\Delta_{i-1}S_i
+
B_{i-1}e^{r_{i-1}\Delta t}
-
V_i.
\]

The bank account is rebalanced according to

\[
B_i
=
\Delta_{i-1}S_i
+
B_{i-1}e^{r_{i-1}\Delta t}
-
\Delta_iS_i.
\]

Both constant and time-varying risk-free rates are supported.

---

### MarketData

`MarketData` reads and processes the supplied:

- `interest.csv`
- `sec_GOOG.csv`
- `op_GOOG.csv`

The option market value is calculated as

\[
V_i =
\frac{\text{best bid}+\text{best offer}}{2}.
\]

Risk-free rates in `interest.csv` are converted from percentage form to decimal form.

Time to maturity is determined using the trading dates present in the supplied GOOG market data and converted to years using 252 trading days per year.

## Task 1: Simulated Delta Hedging

Parameters:

```text
S0    = 100
T     = 0.4
mu    = 0.05
sigma = 0.24
r     = 0.025
K     = 105
N     = 100
Paths = 1000
```

The program generates:

- 1,000 simulated stock-price paths
- 1,000 corresponding Black-Scholes call-price paths
- dynamic Delta hedges for all paths
- terminal cumulative hedging errors

### Terminal Hedging Error Results

```text
Number of paths:       1000
Mean:                  -0.006533
Standard deviation:     0.564338
Minimum:               -2.35417
Maximum:                2.13087
```

The mean terminal hedging error is close to zero, indicating that the simulated hedge does not exhibit a large systematic bias. The remaining dispersion is caused by discrete rebalancing rather than continuous hedging.

## Task 2: GOOG Market Data

The real-data experiment uses:

```text
Start date:       2011-07-05
End date:         2011-07-29
Expiration:       2011-09-17
Strike:           500
Option type:      Call
Observations:     19
```

For every trading date, the program calculates:

- adjusted GOOG stock price
- option market price
- implied volatility
- Black-Scholes Delta
- unhedged PNL
- Delta-hedged PNL

The PNL of the unhedged short option is

\[
PNL_i=V_0-V_i.
\]

The PNL with the hedge is defined as the cumulative hedging error.

### Key Results

```text
Initial stock price:         532.44
Initial option price:         44.20
Initial implied volatility:    0.262203
Initial Delta:                 0.722613

Final unhedged PNL:          -62.6000
Final hedged PNL:            -12.7940
Absolute loss reduction:      79.56%
```

The dynamic Delta hedge substantially reduced the loss relative to leaving the short call position unhedged, although it did not eliminate the loss completely.

## Compilation

The project uses C++11.

From the `Dynamic_Delta_Hedging` directory:

```bash
g++ -Wall -Wextra -pedantic -std=c++11 \
Option.cpp \
BlackScholesModel.cpp \
Simulation.cpp \
DeltaHedger.cpp \
MarketData.cpp \
main.cpp \
-o main
```

Run the program with:

```bash
./main
```

The program runs the unit tests and then executes both Task 1 and Task 2.

## Assumptions

The implementation follows the project assumptions:

- European options
- no dividends during the analyzed period
- no transaction costs
- daily hedge rebalancing
- 252 trading days per year
- Black-Scholes pricing model
- implied volatility recovered from observed option market prices
- supplied market-data files are not manually modified
